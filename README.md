# backend-template

Шаблон репозитория для backend-сервиса на Node.js.

## Требования

Установленный pnpm:

```bash
curl -fsSL https://get.pnpm.io/install.sh | sh -
```

## Начало работы

```bash
pnpm install
```

## Команды

| Команда | Что делает |
|---|---|
| `pnpm dev` | Запускает проект в режиме разработки с перезапуском при изменениях |
| `pnpm build` | Очищает `dist/` и собирает TypeScript из `src/` |
| `pnpm start` | Запускает собранный код из `dist/` |
