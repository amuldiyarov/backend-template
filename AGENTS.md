# Инструкции для агентов

Запускай node и все скрипты только через pnpm: `pnpm exec node`, `pnpm run <script>`.

В относительных импортах указывай расширение `.ts`: `import { x } from './x.ts'`.

Форматирование и линт: Biome. Проверка `pnpm check`, автоисправление `pnpm format`.

Не обходи git-хуки (`--no-verify`, `LEFTHOOK=0`). Если хук упал, исправь причину:
`pnpm format` для форматирования, ошибки типов в коде.

Сообщения коммитов в формате Conventional Commits: `type(scope): описание`.
Типы: feat, fix, refactor, docs, test, build, ci, chore. Описание на английском,
в нижнем регистре, без точки в конце. Проверяется хуком commit-msg.

Тесты: Vitest. Файлы `*.test.ts` рядом с проверяемым модулем, запуск `pnpm test`.
Для новой логики пиши тесты.

Не коммить в `main` напрямую: работай в ветке и открывай pull request.
Ветку называй по типу изменения: `feat/...`, `fix/...`, `ci/...`.
